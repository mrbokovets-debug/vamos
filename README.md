¡Vamos! — первая версия приложения для изучения испанского.

Внутри:
- 5 карточек за урок, варианты ответа и обратная связь
- испанское произношение через голос браузера
- очки и сохранение части прогресса на устройстве
- адаптация под экран iPhone

Как открыть:
1. Распакуй ZIP.
2. Открой index.html в браузере для тестирования.
3. Для установки на главный экран iPhone лучше разместить файлы на HTTPS-хостинге (например, GitHub Pages).
4. Открой опубликованный сайт в Safari → «Поделиться» → «На экран Домой».

Это прототип, не приложение из App Store. В демоверсии пока 3 набора по 5 фраз; ежедневная автоматическая выдача новых уроков и синхронизация между устройствами ещё не подключены.
