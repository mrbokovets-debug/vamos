# ¡Vamos! — испанский каждый день

Тренажёр испанского: 5 фраз в день с вариантами ответа, произношением и очками.
Сайт: https://mrbokovets-debug.github.io/vamos/

## Как устроено
- `index.html` — приложение.
- `lessons.json` — все уроки. Каждый день в конец списка `lessons` добавляется новый урок:
  `{"day": N, "date": "ГГГГ-ММ-ДД", "tip": "совет дня", "cards": [5 × {"es","ru","pron","hint"}]}`.
- `sw.js` — офлайн-режим; сначала берёт свежие файлы из сети, поэтому новые уроки приходят сами.

Прогресс хранится на телефоне. Следующий урок открывается на следующий день после прохождения текущего (или сразу, кнопкой, если он уже есть).
